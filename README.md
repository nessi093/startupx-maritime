# StartupX — Maritime Enterprise OS (2026)

> Корпоративная операционная платформа для коммерческого флота: автоматизация судовой документации, спутниковая телеметрия, предиктивное снабжение и калькулятор окупаемости в строгой дизайн-системе Linear / Apple Pro (Monochrome Titanium & Silver).

---

## 🚀 Деплой на GitHub Pages за 1 минуту

Репозиторий готов для мгновенного бесплатного хостинга через **GitHub Pages** без необходимости сборки (zero-build static hosting):

1. **Создайте репозиторий на GitHub** (например, `maritime-startupx`).
2. **Отправьте код в репозиторий:**
   ```bash
   git remote add origin https://github.com/<ВАШ_USERNAME>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git branch -M main
   git push -u origin main
   ```
3. **Включите GitHub Pages в настройках репозитория:**
   - Перейдите в **Settings** &rarr; **Pages**
   - В разделе **Build and deployment** &rarr; **Source** выберите **Deploy from a branch**
   - Выберите ветку `main` и папку `/(root)`
   - Нажмите **Save**
4. Через 30–60 секунд ваш сайт будет доступен по адресу:
   ```
   https://<ВАШ_USERNAME>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/
   ```

## 🛠 Архитектура и структура проекта

- `index.html` — Главная страница платформы (Hero с живым превью дашборда, полоса стандартов IMO/SOLAS, двухуровневая Bento-сетка, таблица сравнения с устаревшими системами, интерактивный калькулятор Unit-экономики, векторный SVG-график, таймлайн дорожной карты, тарифная сетка, компетенции команды, FAQ-аккордеон и модальное окно пилотного запуска).
- `css/style.css` — Строгая серо-серебристая дизайн-система в стиле Linear, Apple Pro и Vercel (`#09090b` Deep Zinc Black, титановые бейджи, Spotlight-подсветка границ, адаптивность под мобильные устройства).
- `js/app.js` — Интерактивные модули:
  - Сегментированные вкладки панели управления
  - Калькулятор Unit-экономики с ползунками B2C ($5/мес) и B2B ($60/мес)
  - Геометрически точный SVG-график с интерактивными тултипами по кварталам Q1–Q4
  - Интерактивный FAQ-аккордеон
  - Модальное окно заявки на пилот с генерацией проверочного кода `#PLT-2026-XXXX`
  - Микро-параллакс 60 FPS на `requestAnimationFrame`
